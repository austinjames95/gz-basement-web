Source code for the official website of Ground Zero Basement, RPI's underground home of Music, Arts & Culture.

All code for this site should be handwritten without the use of AI tools / coding agents, these are strictly prohibited to committing changes to this repository. This repo should be a space for students interested in web design and computer programming to learn and contribute to the ground zero basement website.

For permissions look at the [license](https://github.com/gz-basement/gz-basement.github.io/?tab=GPL-2.0-1-ov-file#readme).
